# MVP Generico - Estimativa Automatica de Deducoes

## Objetivo
Permitir que o sistema gere deducoes previstas automaticamente ao lancar receitas, de forma generica para diferentes tipos de negocio, com foco em empresas com faturamento anual previsto de ate 1.000.000.

## Escopo do MVP
1. Gerar deducao prevista automaticamente para receitas empresariais.
2. Basear o percentual de deducao em faixas de faturamento anual previsto (RBT12 estimado).
3. Permitir revisao mensal para ajustar previsao versus valor real apurado.
4. Manter rastreabilidade completa de calculo e ajustes.

## Fora de Escopo do MVP
1. Apuracao fiscal oficial automatica sem revisao humana.
2. Regras tributarias especificas por CNAE, municipio ou regime complexo.
3. Integracoes externas com SEFAZ, prefeitura, banco ou ERP.

## Bloco 1 - Dados

### 1.1 Perfil Tributario da Empresa
Campos minimos por empresa:
1. companyId
2. taxationMode: estimated_generic
3. annualRevenueForecast: number
4. reviewPolicy: monthly_required
5. createdAt
6. updatedAt

### 1.2 Tabela de Faixas de Estimativa
Estrutura sugerida:
1. id
2. minAnnualRevenue
3. maxAnnualRevenue
4. estimatedDeductionRate
5. isActive
6. createdAt
7. updatedAt

Faixas padrao iniciais para publico ate 1M (editaveis):
1. 0 a 180.000
2. 180.000,01 a 360.000
3. 360.000,01 a 720.000
4. 720.000,01 a 1.000.000

Observacao:
1. O percentual de cada faixa deve ser configuravel por ambiente/produto e sobrescrevivel por empresa.

### 1.3 Metadados no Lancamento (Previsao)
Ao gerar deducao prevista, gravar:
1. sourceType: tax_estimation
2. autoGenerated: true
3. reviewStatus: suggested
4. confidence: 1.0 (regra deterministica)
5. suggestionReason: faixa anual + aliquota aplicada
6. linkedEntryId: id da receita de origem
7. estimationSnapshot:
- annualRevenueForecastUsed
- matchedBracketId
- matchedRate
- formulaVersion
- calculatedAt

### 1.4 Registro de Revisao Mensal
Criar entidade de reconciliacao mensal:
1. companyId
2. month
3. estimatedTotalDeductions
4. actualTotalDeductions
5. adjustmentValue
6. status: open | reconciled
7. reviewedBy
8. reviewedAt
9. notes

## Bloco 2 - Regras

## 2.1 Regra de Geracao Automatica
Evento disparador:
1. Novo lancamento de receita empresarial aprovado no mes aberto.

Pre-condicoes:
1. Perfil tributario ativo para a empresa.
2. annualRevenueForecast preenchido e maior que zero.
3. Existe faixa ativa correspondente ao annualRevenueForecast.
4. Lancamento nao eh deducao, nao eh estorno e nao eh pessoal.

Calculo:
1. Selecionar faixa por annualRevenueForecast.
2. Aplicar estimatedDeductionRate na receita.
3. Formula:
- deducaoPrevista = receita * (aliquotaEstimativa / 100)
4. Arredondar para 2 casas decimais.

Acao:
1. Criar lancamento em grupo deductions.
2. Vincular deducao a receita via linkedEntryId.
3. Marcar como autoGenerated e reviewStatus=suggested.

### 2.2 Idempotencia
Chave recomendada:
1. companyId + month + linkedEntryId + sourceType(tax_estimation) + formulaVersion

Comportamento:
1. Se chave ja existir, atualizar valor previsto se receita foi alterada.
2. Nunca criar duplicata para o mesmo evento de receita.

### 2.3 Atualizacao por Edicao da Receita
Quando receita vinculada for alterada:
1. Recalcular deducao prevista vinculada.
2. Registrar historico de alteracao.

Quando receita vinculada for removida:
1. Remover ou inativar deducao prevista vinculada.
2. Registrar historico de remocao automatica.

### 2.4 Reconciliacao Mensal
No fechamento mensal:
1. Usuario informa total real de deducoes apuradas (ou itens reais lancados).
2. Sistema calcula diferenca para previsoes existentes.
3. Sistema gera lancamento de ajuste:
- positivo se faltou deducao
- negativo se sobrou deducao
4. Marca reconciliacao mensal como reconciled.

### 2.5 Guardrails
1. Mes fechado: nao permitir geracao/edicao automatica.
2. Toda regra deve ser versionada (formulaVersion).
3. Todas as alteracoes devem ir para trilha de auditoria.
4. Exibir aviso obrigatorio: previsao deve ser validada pelo contador.

## Bloco 3 - UX de Revisao Mensal

## 3.1 Experiencia no Lancamento de Receita
Ao salvar receita empresarial:
1. Exibir aviso nao bloqueante:
- "Deducao prevista automatica criada com base na sua faixa anual de faturamento."
2. Mostrar valor previsto e aliquota aplicada.
3. Link rapido para ver lancamento de deducao criado.

### 3.2 Tela de Revisao de Deducoes Previstas
Filtros:
1. empresa
2. mes
3. status de revisao
4. faixa aplicada

Colunas:
1. receita de origem
2. valor da receita
3. aliquota estimada
4. deducao prevista
5. status
6. acoes

Acoes por item:
1. aprovar
2. editar manualmente
3. rejeitar justificando
4. abrir origem vinculada

### 3.3 Card de Reconciliacao Mensal
No fluxo de fechamento:
1. total previsto no mes
2. total real informado/apurado
3. diferenca
4. botao "Gerar ajuste"
5. botao "Concluir reconciliacao"

### 3.4 Mensagens de Transparencia
1. "Este valor e uma estimativa para planejamento e pode diferir do valor fiscal oficial."
2. "Valide com seu contador antes de obrigacoes oficiais."

## Criterios de Aceite do MVP
1. Toda receita empresarial elegivel gera deducao prevista automaticamente.
2. Nao ha deducoes previstas duplicadas para a mesma receita.
3. Alterar receita atualiza deducao prevista vinculada.
4. Fechamento mensal permite reconciliar previsto versus real com ajuste contabil.
5. Auditoria registra criacao, recalculo, edicao, rejeicao e ajuste.
6. Mes fechado bloqueia automacao e alteracoes automaticas.

## KPI Inicial (MVP)
1. Cobertura automatica: percentual de receitas com deducao prevista gerada.
2. Divergencia media: diferenca percentual entre previsto e real por mes.
3. Tempo de revisao: minutos para reconciliacao mensal.
4. Taxa de ajustes manuais: percentual de itens ajustados pelo usuario.
