# Task 1.4 - Design Tokens and Theming

## Summary
Implemented a reusable token and theming foundation based on the workspace prototype design. The app now supports persisted light/dark mode, Figtree typography, and token-driven styling across the shell, navigation, and shared screen container.

## Details
The prototype handoff in `design/README.md` and `design/ef-ui.jsx` defined the source token palette, typography, and dark-mode values. I translated those values into CSS custom properties in `src/styles/global.css` and set up the app to load Figtree from Google Fonts.

A new `ThemeProvider` in `src/theme.tsx` owns the current mode and persists it in localStorage under `empresa-facil-theme`. An inline boot script in `index.html` sets the initial `data-theme` before React mounts so the page loads in the correct theme without a flash. The shared `ThemeToggle` lives in the screen header so every top-level route can switch modes without changing navigation flow.

I updated the shell, sidebar, screen container, and dashboard card styles to consume the new design tokens. The sidebar now uses the forest-green palette from the prototype, while the content area, cards, borders, and text now reflect the warm off-white system in light mode and the darker prototype palette in dark mode.
