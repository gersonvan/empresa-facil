# Task 1.2 - Core data model and multi-company workflow

## Summary
Implemented a minimal, explicit core model for companies, launch entries, month lifecycle state, and user context with multi-company support. Added deterministic contracts for ingestion/calculation and a validation test proving required queries and separation behavior.

## Details
1. Created domain entities and validators for company, launch entry, month state, and user context in `src/domain.js`.
2. Implemented `CoreRepository` in `src/repository.js` with storage and query methods by company, month, and cost type.
3. Added month status lifecycle handling (`open`, `in_review`, `closed`) with explicit transition rules and persisted month state per company/month key.
4. Added explicit data contract and deterministic mappers for downstream ingestion and calculations in `src/contracts.js`.
5. Exposed the full contract through `src/index.js`.
6. Added `tests/core-model.test.js` and validated all acceptance criteria using `npm test`.
