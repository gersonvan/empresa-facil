# Task 2.2 - Manual entry and spreadsheet import pipeline

## Summary
Implemented manual launch create/update flow and a spreadsheet import pipeline with row-level validation feedback. Imported rows are normalized to the same launch-entry model used by manual input and persisted with company/month/cost-type separation.

## Details
1. Extended repository with `getLaunchEntryById` and `updateLaunchEntry` to support manual update flow without changing company ownership of existing entries.
2. Added `src/ingestion.js` with:
   - Manual entry normalization and create/update APIs.
   - CSV parsing with quoted-field handling.
   - Excel-style row import support via structured row objects.
   - Row-level validation and actionable rejection messages.
3. Enforced strict month validation (`YYYY-MM` with month range 01..12) to reject malformed rows such as `2026-13`.
4. Exported ingestion APIs from `src/index.js`.
5. Added `tests/ingestion-pipeline.test.js` covering manual create/update, multi-row import, malformed row rejection feedback, and separation guarantees.
6. Updated test script to run both core-model and ingestion tests.
