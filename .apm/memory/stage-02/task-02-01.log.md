# Task 2.1 - Fast launch forms and guided daily flow

## Summary
Implemented a guided 3-step manual launch flow with minimal required fields and integrated dashboard next-step prompts that route users directly to the most relevant launch intent.

## Details
Cross-agent dependencies were integrated first:
- `src/domain.js`: enforced `launchEntry` constraints (`companyId`, `month`, `costType`, `description`, `amount`).
- `src/repository.js`: reviewed filtering/persistence shape by company, month, and cost type.
- `src/contracts.js` and `src/index.js`: aligned output with ingestion contract (`toIngestionRecord`) and exported API concepts.

Implementation work:
1. Replaced the placeholder launch screen with a guided three-step flow:
   - Step 1: explicit intent (`Empresa` or `Pessoal`) using accessible pressed-state buttons.
   - Step 2: minimal required fields (`Descrição`, `Valor`) plus deferred optional field (`Observação`) behind a details disclosure.
   - Step 3: confirmation and submit with default month/company context shown.
2. Added validation focused on minimal required data (description and positive numeric amount).
3. Built submission payload through `createLaunchEntry(...)` and mapped it with `toIngestionRecord(...)` to keep manual flow conceptually aligned with the shared data contract.
4. Added dashboard daily guidance card (“Próximo passo do dia”) with direct actions:
   - `Registrar empresa` -> `/launch?intent=company`
   - `Registrar pessoal` -> `/launch?intent=personal`
5. Kept responsive behavior intact with launch-specific CSS that scales from single-column mobile to two-option intent grid on desktop.
6. Added lightweight declaration files (`src/domain.d.ts`, `src/contracts.d.ts`) so TypeScript can safely consume existing JS domain/contract modules.
