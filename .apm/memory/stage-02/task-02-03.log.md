# Task 2.3 - Monthly DRE summary and main indicators

## Summary
Implemented reusable monthly DRE summary transformations, compact indicators, and cost-group summaries on top of the existing calculation output contract. The resulting payload supports both dashboard and detailed DRE report views without recalculation.

## Details
Integrated with the existing deterministic calculation output from Stage 1 and avoided duplicating business logic.
Added transformation functions to convert calculation output into monthly summary, indicator, and cost-group payloads.
Added a dedicated monthly summary contract schema to make output expectations explicit and stable.
Added an overview builder that composes summary, indicators, and cost groups and exposes a shared summary payload for dashboard and report contexts.
Updated public exports so consumers can use these transformations directly from the package entry.
Expanded tests to validate required summary fields, compact indicators, cost-group percentages, and cross-view payload consistency.
